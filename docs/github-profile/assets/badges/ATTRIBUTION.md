# Badge artwork

Java, AWS, Google Cloud, OpenCV and scikit-learn icon paths are from [Devicon](https://github.com/devicons/devicon), under the included MIT licence. The AWS lettering is white for visibility on the dark badge. The Google Cloud icon retains its four-colour layout using blue #4285F4, red #EA4335, yellow #FBBC05 and green #34A853.

The SQL badge uses a generic database cylinder drawn for this profile; SQL has no single vendor-neutral product logo.

The OpenCV badge preserves the source icon's red, green and blue colours.

Codex uses OpenAI artwork distributed by [Lobe Icons](https://github.com/lobehub/lobe-icons), under its included MIT licence. The OpenAI and Codex names and marks belong to OpenAI.

Cursor and Claude icon paths are from [Simple Icons](https://github.com/simple-icons/simple-icons), under its included CC0 licence. Brand marks belong to their respective owners. Claude is shown in terracotta; Cursor and Codex are white for the dark badge background.

The scikit-learn badge preserves the original orange-and-blue artwork.
